Three ways to run the platform:

1. PRODUCTION (Docker) - Recommended for deployment
   $ chmod +x setup.sh && ./setup.sh
   Time: 5-15 minutes first run
   Access: http://localhost:3000

2. DEMO MODE - No API key needed
   $ chmod +x run_demo.sh && ./run_demo.sh
   Time: 2-3 minutes
   Access: http://localhost:3000 (simulated data)

3. LOCAL DEV - Direct Python/Node without Docker
   $ chmod +x run_local.sh && ./run_local.sh
   Time: 3-5 minutes
   Access: http://localhost:3000, http://localhost:8000
   Features: Hot reload enabled

Environment Variables (in .env):

LLM Provider:

  OLLAMA_BASE_URL=http://localhost    (Ollama)

Database:

  DB_USER=traffic_admin
  DB_PASSWORD=auto-generated
  DB_NAME=traffic_intelligence

Redis:
  REDIS_URL=redis://:password@redis:6379
  REDIS_PASSWORD=auto-generated

YOLO:
  YOLO_MODEL_PATH=/app/models/yolov8n.pt
  DETECTION_CONFIDENCE=0.5
