Why this exists.

Problem

Traffic footage is noisy, multi-source, and under-read.

Smart-city operators have hundreds of RTSP feeds, dashcams, and uploaded clips. Most pipelines detect objects but lose identity across frames, can't read plates, and surface raw events instead of insight. Analysts end up scrubbing video manually.

Solution

One pipeline from pixels to natural-language answers.

A six-stage async pipeline fuses YOLOv8 detection, DeepSORT tracking, EasyOCR plate reading, and incident heuristics into a single event stream — then layers a Gemini-backed chat agent on top, grounded in live detection data.

Impact

Answers in seconds, not hours.

Operators ask "how many trucks passed in the last hour?" instead of scrubbing 60 minutes of footage. Stopped-vehicle and congestion alerts fire the moment they happen. Ingest works on any camera source out of the box — including YouTube URLs.

03 /

How it's built.

Six asyncio stages run concurrently per session. Frames flow left to right with a back-pressure cap of 100 on the detection queue, so a slow stage drops frames instead of building unbounded memory. DB writes are batched every 5 s; metrics broadcast every 1 s.

05 /

What it does, end-to-end.

Ingest anything

RTSP, RTMP, HTTP(S), YouTube (resolved via yt-dlp), webcam, or uploaded MP4 / WebM / MOV / MKV. One endpoint, one pipeline.

Detect + track

Six vehicle and pedestrian classes via YOLOv8 with persistent DeepSORT IDs that survive occlusion.

Read plates

EasyOCR license-plate extraction every third frame per detection, with confidence scoring (threshold 0.3) and append-only archival.

Catch incidents

Concurrent heuristics for stopped vehicles, congestion clusters, crowds, and accident patterns — all on the same frame stream.

Chat-over-data

Gemini-backed agent grounded in live detection + incident data. Ask "how many trucks went through in the last hour?" in plain English.

Reconnect forever

Streams drop. The pipeline retries 5× with 5 s backoff and the frontend WebSocket reconnects with exponential backoff. No manual restarts.

Back-pressure honest

The detection queue caps at 100 frames. When a stage can't keep up it drops frames instead of ballooning memory — production-safe by default.

Observable

Grafana dashboards and Prometheus metrics out of the box: FPS, detection latency, DB write throughput, per-session health.

07 /

Try it locally.

~/multimodal-traffic-intelligence
# 1. clone
$ git clone https://github.com/Bharathkondur/Multimodal-Traffic-Intelligence-platform.git
$ cd Multimodal-Traffic-Intelligence-platform

# 2. configure (optional: GOOGLE_API_KEY for chat)
$ cp .env.example .env

# 3. run
$ docker compose up --build

# open:
http://localhost:3000   → dashboard
http://localhost:8000/docs → API (Swagger)
http://localhost:3001   → Grafana (admin/admin)

Full prerequisites, environment variables, and migration commands live in the repo's README.
