INTEGRATION & DEPENDENCIES
================================================================================

External Dependencies:
  • ultralytics (YOLO object detection)
  • easyocr (text recognition)
  • redis[asyncio] (async Redis client)
  • sqlalchemy (database ORM)
  • fastapi (web framework)
  • langchain (LLM framework)
  • langgraph (agentic framework)
  • pydantic (data validation)

Internal Dependencies:
  • backend/database/ (models, queries, connection)
  • backend/stream/processor.py (StreamProcessor)
  • backend/agents/graph.py (TrafficAnalysisGraph)
  • backend/config.py (Settings)
  • backend/api/routes.py (API endpoints)

Data Flow:
  1. API receives video upload/stream start → processing.detection/stream
  2. Detection/stream loads model via models.detection/ocr
  3. StreamProcessor processes frames → saves to DB
  4. Report request → processing.reports → agents.langgraph_agent
  5. LangGraph queries DB, returns analysis → report generated
  6. Session cleanup → processing.cleanup (removes files, updates status)
  7. Cache operations → utils.redis_client (store/retrieve data)
