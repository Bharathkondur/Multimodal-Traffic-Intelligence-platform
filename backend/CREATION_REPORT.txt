1. PROCESSING PACKAGE MODULES
─────────────────────────────────────────────────────────────────────────────

start_detection_pipeline(session_id, video_path, settings)
  • Loads YOLOv8 model via models.detection module
  • Creates StreamProcessor for video files
  • Processes frames frame-by-frame with configurable parameters:
    - FPS: 30 (input), 10 (target processing)
    - Frame size: 1920x1080
    - Batch size: 8, workers: 4
    - DB batch writes: every 5s or 50 detections
  • Saves detections to database via AsyncSessionFactory
  • Updates session status (COMPLETED or FAILED)
  • Runs as background asyncio task
  • Handles errors gracefully with logging

start_stream_pipeline(session_id, stream_url, settings, stream_type)
  • Creates StreamProcessor for RTSP or HTTP streams
  • Supports both RTSP and HTTP protocols
  • Real-time processing at 15 FPS
  • Automatic reconnection with 5 attempts, 5s delay
  • Configurable stream timeout (default: 300s)
  • Frame processing: 1920x1080, 4 batch size, 2 workers
  • Updates session status on completion or failure
  • Graceful error handling with retry logic

generate_report_task(session_id, report_type, query, db_session)
  • Queries detection summary, incidents, vehicle counts
  • Feeds data to LangGraph agent (process_message)
  • Report types: "shift", "incident", "summary", "custom"
  • Returns structured report with:
    - report_id (UUID)
    - statistics (detections, incidents, vehicle breakdown, confidence)
    - summary (LLM-generated natural language analysis)
    - incidents (top 10 detected)
    - recommendations (AI-generated, top 5)
    - raw_data (query results)
  • Saves report to database
  • LLM error handling with fallback responses

cleanup_session(session_id, db_session)
  • Stops active StreamProcessor for session
  • Updates session status to COMPLETED
  • Removes uploaded video files from disk
  • Cleans up temporary directories (/tmp/traffic_*, /tmp/detections_*)
  • Logs all cleanup actions
  • Maintains registry of active processors
  • Graceful error handling

2. MODELS PACKAGE MODULES
─────────────────────────────────────────────────────────────────────────────

load_model(model_path="yolov8n.pt", device="auto")
  • Uses ultralytics.YOLO for loading
  • Singleton pattern caching in _model_cache
  • Auto-downloads yolov8n.pt if not found
  • Auto-detects GPU/CPU:
    - "auto": Detects CUDA, uses GPU[0] if available, else CPU
    - Can specify device index or "cpu"
  • Supports all model sizes: yolov8n/s/m/l (and XL)
  • Cache key: model_path + device combination
  • Helper functions:
    - clear_cache(): Clear model cache
    - get_cache_info(): Get cache metadata

get_model(model_path="yolov8n.pt", device="auto")
  • Alias for load_model with same caching mechanism
  • Convenience wrapper

load_ocr_model(gpu=False)
  • Uses easyocr.Reader for English text recognition
  • Singleton pattern caching in _ocr_reader
  • GPU/CPU detection:
    - gpu=True: Attempts CUDA, falls back to CPU if unavailable
    - gpu=False: Uses CPU
  • License plate and text OCR support
  • Helper functions:
    - clear_ocr_cache(): Clear reader cache
    - is_ocr_loaded(): Check if cached
    - perform_ocr(image_path, gpu): Direct OCR convenience

get_ocr_reader(gpu=False)
  • Alias for load_ocr_model with same caching mechanism
  • Convenience wrapper

3. UTILS PACKAGE MODULES
─────────────────────────────────────────────────────────────────────────────

init_redis(redis_url) -> Optional[Redis]
  • Initializes async Redis client with redis.asyncio
  • Connection pooling configuration:
    - Socket connect timeout: 5s
    - Socket keepalive: enabled
    - Health check interval: 30s
  • Performs health check via PING
  • Graceful fallback if Redis unavailable
  • Returns None if initialization fails
  • Global singleton: _redis_client

get_redis() -> Optional[Redis]
  • Returns cached Redis client or None

check_health() -> bool
  • Sends PING to Redis
  • Returns True if healthy, False otherwise
  • Used during init and monitoring

cache_set(key, value, ttl=300) -> bool
  • Sets key with JSON serialization
  • TTL support (default 300s)
  • Graceful fallback to False if Redis unavailable
  • Returns True on success, False on error

cache_get(key) -> Optional[Any]
  • Gets value with JSON deserialization
  • Falls back to string if not JSON
  • Returns None if key not found or Redis unavailable
  • Handles JSON decode errors gracefully

Additional functions:
  - cache_delete(key): Delete single key
  - cache_clear_pattern(pattern): Delete keys by pattern
  - close_redis(): Close connection on shutdown

4. LANGGRAPH AGENT ADAPTER
─────────────────────────────────────────────────────────────────────────────

process_message(session_id, message, db_session=None) -> dict
  • Routes message through TrafficAnalysisGraph
  • Maintains in-memory conversation history per session
  • Query type detection:
    - "report": Report requests
    - "alert": Incident/alert queries
    - "scene": Current situation queries
    - "analysis": Data analysis requests
    - "question": General questions
    - "unknown": Unclassified
  • Returns structured response:
    {
      "response": str,           # LLM response
      "query_type": str,         # Detected type
      "data": dict,              # Analysis data
      "session_id": str,         # Session ID
      "conversation_turn": int,  # Turn count
    }
  • Error handling with meaningful fallback responses
  • Conversation management functions:
    - get_conversation_history(session_id)
    - clear_conversation_history(session_id)
    - get_all_active_sessions()
